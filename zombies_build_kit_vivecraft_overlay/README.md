# Zombies Build Kit Vivecraft Overlay

This optional resource pack supplies Vivecraft-specific held-item transforms for shared Zombies Build Kit weapon models. It depends on the Core resource pack and matching datapack.

The overlay overrides Core item models in the `zbk:` asset namespace.

## Installation

Download this optional overlay from the [resource pack release](https://github.com/Stews-Creations/zbk_resourcepacks/releases/latest) and enable it above `Zombies Build Kit Core`. Map authors can include map-specific Vivecraft assets in their world bundles. Refresh resources with F3+T after changing files.

This overlay contains shared weapon overrides only. The map-specific bow transforms are owned by the DE Vivecraft overlay. `VERSION` and the `zbk.version` metadata field identify this pack as version 1.0.0; Minecraft's 26.2 resource format remains at 88.0.
