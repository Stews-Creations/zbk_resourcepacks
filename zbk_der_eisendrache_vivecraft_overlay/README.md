# ZBK Der Eisendrache Vivecraft Overlay

This optional resource pack supplies Vivecraft bow transforms for the Der Eisendrache bow models. It depends on `ZBK Der Eisendrache`, `Zombies Build Kit Core`, and the matching datapacks.

## Installation

Enable this overlay above `ZBK Der Eisendrache`, the Core Vivecraft overlay, and the Core and map resource packs. The overlay includes only map bow model overrides; the DE base pack owns their textures, item definitions, and non-VR models. Refresh resources with F3+T after replacing files.

## Contents and license

This pack restores the original DE bow VR model transforms under the `zbk_der_eisendrache` namespace. ZBK custom assets use the project license and media permission included here. Third-party notices are preserved in `LICENSES/`.
