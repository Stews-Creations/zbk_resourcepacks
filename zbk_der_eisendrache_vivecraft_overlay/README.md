# ZBK Der Eisendrache Vivecraft Overlay

This optional resource pack supplies Vivecraft bow transforms for the Der Eisendrache bow models. It depends on `ZBK Der Eisendrache`, `Zombies Build Kit Base`, and the matching datapacks.

## Installation

Enable this overlay above `ZBK Der Eisendrache`, the base pack Vivecraft overlay, and the base pack and map resource packs. The overlay includes only map bow model overrides; the DE map pack owns their textures, item definitions, and non-VR models. Refresh resources with F3+T after replacing files.

## Contents and license

Within `models/quest/bows/vr/<bow>/`, `idle.json` sits beside the numbered poses in `draw/`. The `right_hand/` variants use the same layout. Bow item definitions retain their existing `quest/bows/weapons/` IDs and reference these model paths.

This pack restores the original DE bow VR model transforms under the `zbk_der_eisendrache` namespace. ZBK custom assets use the project license and media permission included here. Third-party notices are preserved in `LICENSES/`.
