# ZBK Nacht der Untoten resource pack

This optional map resource pack supplies Nacht der Untoten audio and assets under the `zbk_nacht_der_untoten` namespace. It requires the matching ZBK base pack datapack and resource pack.

## Installation

Enable `Zombies Build Kit Base` below `ZBK Nacht der Untoten`. Keep unrelated map packs disabled for the world. Refresh client resources with F3+T after replacing either pack.

## Contents and license

The pack supplies Dr. Monty dialogue, the barrel Easter egg, the flickering-light sound, and the `zbk_nacht_der_untoten:fade_black` cutscene font. The full ten-track regular radio playlist, shared rounds, dogs, teleporters, menu music, and character callouts come from the base pack. Install this pack with the matching Nacht datapack; installing it alone does not add gameplay. ZBK custom assets use the project license and media permission included here. Third-party notices are preserved in `LICENSES/`.
